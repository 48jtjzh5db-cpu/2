☁️ 雲端同步 (GitHub Gist)

使用 GitHub Gist 進行跨設備同步。首次使用需要設定 Personal Access Token。
💻 電腦端設定：
1. 點此建立 Token（勾選 gist 權限）
2. 建立後會顯示一次性的 Token 字串
3. 立即複製並儲存（關閉頁面後就看不到了！）
📱 手機端設定：
• 使用同一個 Token（一個 Token 可同時在多個裝置使用）
• 電腦端：點擊「👁️ 顯示」按鈕查看並複製 Token
• 手機端：貼上 Token 並點擊儲存即可同步資料
輸入說明：貼上完整的 Token 字串（通常以 ghp_ 或 github_pat_ 開頭的40-100個字元）

💡 安全提醒：Token 只會儲存在您的瀏覽器本地，不會上傳到任何其他地方。顯示功能僅供臨時查看，5秒後自動隱藏。
⚠️ 設定提示：已匯入雲端設定，請重新設定 GitHub Token 即可開始同步資料。
